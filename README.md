# 周易占卜

一个小巧的周易占卜网页应用：用**铜钱法**或**蓍草法（大衍筮法）**起卦，按朱熹《易学启蒙》的规则取占，并附《周易》原文和白话解读。

完全离线，无需安装，不联网、不收集任何数据。

## 在 Windows 上使用

1. 下载本项目：在 GitHub 页面点 **Code → Download ZIP**，然后解压。
2. **双击 `index.html`**，就会在 Edge 或 Chrome 里打开。

就这样。占卜记录只保存在这台电脑的浏览器里。

> 如果部署到了 GitHub Pages，也可以用 Edge 打开网址，点地址栏右边的「安装此站点为应用」，它就会出现在开始菜单里，断网也能使用。

## 功能

- **占前准备**：净手、静心、三不占、一事一占、不可再三
- **写下问题**：如果最近问过相似的问题，会用「初筮告，再三渎，渎则不告」提醒
- **静心**：跟随呼吸动画，默念所问之事
- **起卦**
  - 铜钱法：三枚铜钱掷六次，字面记 2、背面记 3
  - 蓍草法：四十九根蓍草，分二、挂一、揲四、归奇，三变成一爻；第一爻逐步演示
- **解卦**：显示本卦、之卦、变爻，自动标出这次该看哪一句，并说明依据
- **全文**：卦辞、彖传、大象、六爻爻辞与小象，每一段都有白话解读
- **占卜记录**：保存在本机，可随时回看

### 取占规则（朱熹《易学启蒙·考变占》）

| 变爻数 | 看哪里 |
|---|---|
| 0 | 本卦卦辞 |
| 1 | 本卦变爻的爻辞 |
| 2 | 本卦两个变爻的爻辞，以上爻为主 |
| 3 | 本卦与之卦的卦辞，以本卦为主 |
| 4 | 之卦两个不变爻的爻辞，以下爻为主 |
| 5 | 之卦唯一不变爻的爻辞 |
| 6 | 乾看用九，坤看用六，其余看之卦卦辞 |

### 两种起卦方法的概率

| 爻 | 铜钱法 | 蓍草法 |
|---|---|---|
| 6 老阴 | 1/8 | 1/16 |
| 7 少阳 | 3/8 | 5/16 |
| 8 少阴 | 3/8 | 7/16 |
| 9 老阳 | 1/8 | 3/16 |

随机数来自浏览器的密码学随机源（`crypto.getRandomValues`）。

## 文本来源

- 底本：《周易正义》（武英殿本）
- 对校本：朱熹《周易本义》（四库全书本），小象取自此本，标点为本项目所加
- 两本逐字对校，个别文字依通行本校正，校改记录见 `tools/build_text.py`
- 电子文本取自 MIT 许可的 npm 包 `opencode-tianji@0.6.0`；古籍原文属公有领域
- 白话解读为本项目撰写

## 项目结构

```
index.html          页面
style.css           样式（手机和电脑都适配，支持深色模式）
js/core.js          核心逻辑：八卦、六十四卦、起卦、取占规则
js/app.js           界面与流程
data/text.js        原文（由 tools/build_text.py 生成）
data/plain.js       白话解读
tests/              单元测试
tools/              生成原文数据的脚本
sw.js, manifest.webmanifest, icon*   「安装为应用」与离线缓存
```

## 开发

```bash
npm test                 # 运行测试（需要 Node 18+）
npm run build:text       # 重新生成 data/text.js（需要 Python 3 和 opencc-python-reimplemented）
```
